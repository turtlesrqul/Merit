# Merit PMF Visual Direction

Date: 2026-06-03  
Status: Visual strategy companion, not application implementation  
Purpose: Translate Merit PMF strategy into concrete visual artifacts, product frames, and design language.

## Visual Thesis

Merit's PMF visuals should make one idea instantly legible:

> Recruiters make better early-career shortlist decisions when student work is structured as proof.

The product should not look like a portfolio gallery. It should look like proof infrastructure: clear, inspectable, recruiter-readable, and serious enough for hiring decisions.

### 3. Proof Card Anatomy

Purpose:

Define the atomic product object.

A proof card must show:

- Artifact preview.
- What was built.
- Candidate contribution.
- Skills demonstrated.
- Evidence artifacts.
- Outcome / impact.
- Role relevance.
- Confidence gaps.

Strategic contrast:

- Weak signal: pretty portfolio card with title, image, likes, and no decision context.
- Strong signal: structured proof card with evidence, outcome, fit, and gaps.

Use this board for:

- Student onboarding.
- Project form redesign.
- Recruiter trust testing.
- Brand system development.

## Visual System Rules

### Palette

- Ink for seriousness.
- White and off-white for clarity.
- Signal gold for brand emphasis.
- Proof blue for recruiter actions and role fit.
- Evidence green for validated or complete signals.
- Muted amber for missing evidence or confidence gaps.

### Typography

- Serif for brand statements and strategic boards.
- Sans for product UI and recruiter workflow.
- Mono or small-caps metadata only for evidence labels, dates, scores, and system details.

### Layout

- Use grids, tables, dossiers, and evidence panels.
- Avoid repetitive card galleries.
- Keep radius disciplined.
- Prioritize scannable information over decorative warmth.

### Imagery

Use product and artifact imagery:

- Project screenshots.
- Figma prototypes.
- PDFs.
- Decks.
- GitHub repos.
- Demo videos.
- Usability reports.

Avoid:

- Stock student photos.
- Abstract gradients.
- Decorative blobs.
- Generic dashboard filler.

## PMF Design Principles

### 1. Proof Before Personality

Students should still feel human, but recruiter surfaces must first answer what the candidate can do.

### 2. Fit Before Feed

Discovery is not a social feed. It is a path to shortlist confidence.

### 3. Gaps Are Trust-Building

Show missing evidence. Recruiters trust systems that reveal uncertainty instead of pretending every candidate is perfect.

### 4. Outcomes Beat Engagement

Views, likes, and saves are not hiring signal. Outcomes, evidence, contribution, and role relevance are.

### 5. Concierge Before Automation

The first PMF loop can be manually curated. Automation should follow validated recruiter behavior.

## Recommended Next Design Moves

### For Product

Start with the proof card anatomy and recruiter workspace. These are the buyer-critical visuals.

### For Brand

Use the landing narrative frame to reposition Merit from portfolio platform to proof-of-ability layer.

### For Research

Use the 90-day sprint board and PMF loop during recruiter calls. Ask recruiters to react to the loop and workspace before discussing features.

### For Student Activation

Use the strongest-proof-first flow in onboarding workshops. The student should leave with one complete proof card, not a half-filled profile.

## Final Direction

Merit should look and feel like:

> A proof dossier system for ambitious early talent.

Not:

- A prettier LinkedIn.
- A student portfolio gallery.
- A generic job board.
- A social network for projects.

The visuals should make the commercial loop obvious:

> Better proof creates better recruiter confidence. Better recruiter confidence creates real opportunity. Real opportunity attracts stronger student proof.
